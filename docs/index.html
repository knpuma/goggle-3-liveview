02 / INSTALLATION

The first launch.

On Mac

  1. Open the DMG file.
  2. Drag the app to Applications.
  3. Open it from Applications.

The app is not notarized by Apple. If macOS blocks it, verify the download source and check the individual app-opening option in Privacy & Security: Apple’s official guide. Do not disable Gatekeeper.

On Windows

  1. Right-click the ZIP and choose Extract All.
  2. Open Goggle 3 LiveView.exe.
  3. Keep the other files and the ffmpeg folder beside the executable.

No .NET or developer tools need to be installed. If an unknown-publisher warning appears, verify the source and SHA-256 checksum. Do not disable your antivirus.

On Linux

  1. Download the DEB for Ubuntu 24.04 x64.
  2. In its folder, run sudo apt install ./Goggle-3-LiveView-Linux-x64-0.3.3.deb.
  3. Open Goggle 3 LiveView from the applications menu.

Run the app as your normal user, not with sudo. On a Wayland desktop, XWayland is required. Linux setup and portable instructions →

Which download is right for my computer?

Mac: Apple menu → About This Mac. An Apple M1 or later chip is required; there is no Intel Mac package.

Windows: Settings → System → About. Choose ARM64 for an ARM-based system, or x64 for Intel / AMD.

Linux: tested only on Ubuntu 24.04 on Intel / AMD x64. Other distributions have not been tested. No Linux ARM64 package yet.

Language: Mac and Windows have separate English and Spanish downloads. Linux includes an ES / EN language switch.

03 / SETUP

From USB
to live video.

The same goggles settings work with both applications.

Official DJI manual ↗
  1. 01

    Connect a data cable

    Power on the goggles and connect them to your computer. A charge-only cable will not work. If you have trouble, try a direct connection without a hub.

  2. 02

    Enable OTG Wired Connection

    On the goggles, open:

    Settings › About ›
    OTG Wired Connection

  3. 03

    Enable LiveView sharing

    Push the 5D button backward to open the shortcut menu. Enable liveview sharing to a mobile device via Wi-Fi.

    The setting says Wi-Fi, but this app receives video over USB. Your computer does not need to join the goggles Wi-Fi network.

  4. 04

    Open the viewer and click Connect

    In Multi, select a USB port for each panel. On Windows and Linux, the first connection may request administrator permission to set up the goggles USB adapter. It does not change your Wi-Fi or other networks.

WITHOUT A LINKED AIRCRAFT

Show the goggles screen.

Keep Camera View Recording enabled under:

Settings › Camera ›
Advanced Camera Settings

Keep OTG and LiveView sharing enabled too. To display a flight camera, the goggles must be receiving video from the aircraft or air unit.

View the built-in Multi tutorial

Setting names follow the DJI manual. This project’s USB reception and operation without an aircraft are independent features, not functions documented or endorsed by DJI for this app.

04 / HELP

No video yet?

Start with the cable, OTG
and LiveView sharing.

The app stays on “Waiting for video”
  1. Click Disconnect in the app.
  2. Turn LiveView sharing off and on again on the goggles.
  3. Check OTG, then click Connect again.

Close other viewers using the goggles. If necessary, reconnect the cable. Without an aircraft, check Camera View Recording as well.

Windows does not detect the goggles

Check the data cable and OTG. Microsoft’s RNDIS adapter should appear in Device Manager. Do not replace its driver with Zadig or WinUSB.

In a virtual machine, assign the goggles to Windows through the virtualization software’s USB menu. Only one system can use them at a time.

Linux does not detect the goggles

Check OTG, the USB data cable and the standard Linux rndis_host / usbnet driver. The USB ID is 2ca3:0020. Resolve any 192.168.60.x network conflict before connecting. Do not disable your firewall or change other adapters. Linux troubleshooting →

Where are my recordings?

Original viewer: Movies → Goggle 3 LiveView on Mac; Videos → Goggle 3 LiveView on Windows and Linux.

Multi: Movies → Goggle 3 LiveView Multi.

Click Stop and wait for the MP4 to finish saving. Recordings have no audio. Older Goggles3Mac recordings remain in their original folder.

How do I exit fullscreen?

Press Esc. Windows and Linux also support F11. The fullscreen button is beside Record. In Multi, expanding a panel does not change the recorded mosaic.

What do FPS and bitrate mean?

They describe video processed by your computer, not the goggles display refresh rate or the aircraft radio link. Bitrate is a measurement, not a quality control.

Multi shows decoded FPS. Hover over the counter to see displayed FPS too.

Do I need RC Pro or a linked aircraft?

No RC Pro is required. You can show the goggles screen without an aircraft using the settings above. To display a drone camera, the goggles must be receiving that camera’s signal.

Are my videos uploaded to the Internet?

No. The apps receive video from the goggles and save recordings locally. This website does not include third-party analytics or trackers.
