# Goggle 3 LiveView Multi 0.5.0 · Windows x64

Bring up to four DJI Goggles 3 USB video feeds into one window. Name each pilot, watch a 2×2 mosaic and save individual channels or the whole layout to MP4. No RC Pro or subscription required.

**[Download Multi for Windows x64 →](https://github.com/knpuma/goggle-3-liveview/releases/download/multi-v0.5.0/Goggle-3-LiveView-Multi-Windows-x64-0.5.0.zip)**

**English and Spanish are included.** Switch languages with **ES / EN** inside the app.

## Features

- Four named video panels with independent connection and recording controls.
- Live FPS, resolution and received bitrate for each channel.
- Individual MP4 recordings and a global 1920×1080 mosaic recording at a target 30 fps; both modes can run together.
- Clean fullscreen for one channel or the complete mosaic. Press **Esc** or **F11** to return.
- Local recordings in **Videos → Goggle 3 LiveView Multi**.
- Built-in tutorial for the goggles' USB and LiveView settings.

## Install and connect

1. Use **Windows 11 x64** or **Windows 10 22H2 x64**.
2. Extract the entire ZIP and open **Goggle 3 LiveView Multi.exe**. Keep all included files together. The .NET runtime and encoder are included.
3. On each pair of goggles, enable **Settings → About → OTG Wired Connection** and LiveView sharing from the shortcut menu.
4. Connect USB data cables, select a device in each panel and click **Connect** or **Connect all**. Windows may request administrator approval to configure the goggles' USB network adapters.

Without a linked aircraft, also enable **Camera View Recording** under **Settings → Camera → Advanced Camera Settings**. The video connection uses USB; your computer does not need to join the goggles' Wi-Fi network.
